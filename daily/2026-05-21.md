## 学习笔记

### 核心概念

今天重点是把六个概念区分清楚：LLM 负责生成，prompt 提供指令，context window 决定可见信息，workflow 组织步骤，agent 负责执行，tool use 负责连接外部能力。

### 概念摘要

#### LLM
一句话：LLM 是根据上下文生成下一段最可能内容的大模型。
例子：让模型把一段会议记录整理成摘要。
边界：它会“生成得很像对”，但不等于真的理解或事实核验。

#### prompt
一句话：prompt 是你给模型的指令、背景和约束。
例子：要求模型按“定义 / 例子 / 误区”三段输出。
边界：prompt 写得更清楚，通常更稳定，但不能替代真实信息输入。

#### context window
一句话：context window 是模型当前能看到的输入长度上限。
例子：太长的聊天记录会被截断，模型只能看到最近一部分。
边界：超出窗口的信息不会自动被记住，需要重新整理或摘要。

#### workflow
一句话：workflow 是按顺序组织任务的流程。
例子：先读资料，再写初稿，再人工复核，最后发布。
边界：workflow 负责流程，不负责自己去执行外部动作。

#### agent
一句话：agent 是可以按目标自己调用工具并推进任务的系统。
例子：根据任务自动查资料、写草稿、再输出整理结果。
边界：agent 能行动，不代表可以代替人工确认高风险步骤。

#### tool use
一句话：tool use 是模型调用外部工具完成它单靠文本做不到的事。
例子：调用搜索、文件读取或计算工具。
边界：能调用工具不等于能越权，权限和确认仍要受控制。
